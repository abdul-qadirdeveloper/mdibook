# MediBook

## Stack

- Next.js (App Router) with TypeScript.
- PostgreSQL, accessed through Prisma. PostgreSQL extensions and hand-written SQL migrations are
  allowed where the Prisma schema cannot express a constraint.
- Email delivery for password reset and set-password links: a service is needed but not yet
  chosen. Engineering chooses it at build time and records it here.

Specs must not name technology beyond this list (see the `spec-template` skill).
